One original line roasting a gadget used every day: a fitness tracker that cheers the walk to the fridge, then silently judges you for opening it. Written for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty, $5 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This deterministically writes the roast line to `out/entry.txt` (92 characters, within the 1–200 character gate). Node 22+ standard library only, no dependencies, no network.
